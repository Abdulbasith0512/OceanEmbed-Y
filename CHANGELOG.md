# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-20

### Added
- Orbital to 1000m depth scroll-driven 3D WebGL expedition using React Three Fiber.
- Procedural instanced marine life (schooling fish, rays, jellies, squid, siphonophore colonies).
- Interactive scientific Ocean Explorer (`/explore`) with date, depth, and layer controls.
- Synthetic ocean field data reconstruction boundary with CSV data export.
- Vitest unit test suite and Playwright end-to-end browser test suite.
- Comprehensive project documentation, GitHub templates, and developer tooling configs.

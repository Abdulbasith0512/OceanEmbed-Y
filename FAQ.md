# Frequently Asked Questions (FAQ)

### Q: What is OceanEmbed-X?
A: OceanEmbed-X is a desktop-focused Next.js 15 frontend application created for the Neutrons SIH26066 proposal. It provides a scroll-driven 3D WebGL expedition from orbit down to 1000m depth, followed by an interactive scientific ocean explorer.

### Q: Does OceanEmbed-X require a GPU to run?
A: A hardware WebGL-capable GPU provides the best experience, but standard fallback rendering and software WebGL are supported for browser compatibility testing.

### Q: How do I connect my own backend service?
A: Refer to [`docs/API_INTEGRATION.md`](docs/API_INTEGRATION.md) for details on replacing the mock data service in `lib/api/ocean-service.ts`.
